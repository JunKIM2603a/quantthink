## 입력을 고정한 방법

D2-03 seed42의 BF16 응답은 생성2,425번째 토큰에서 EOS로 끝났고 AWQ 응답은4,096토큰 상한에서 검열됐다. BF16의 EOS 바로 전까지인2,424토큰과, AWQ의 동일한 생성 토큰 수2,424개를 각각 고정한다. 두 경로는 내용이 다르므로 서로 같은 정답·추론 단계라고 가정하지 않는다.

| 고정 입력 | prompt | 생성 prefix | 전체 문맥 | 측정 위치 | 원본의 다음 토큰 |
|---|---:|---:|---:|---|---|
| D2-03_B_pre_eos |71|2424|2495|2366~2494, 연속129개|EOS|
| D2-03_Q_same_length |71|2424|2495|2366~2494, 연속129개|EOS 아님|

0부터 시작하는 logit 위치2494는 전체 입력 마지막 위치이며, 생성2,425번째 토큰을 예측한다. **EOS를 모델 입력에 미리 넣지 않는다.** 생성2,297~2,425번째 토큰에 해당하는 예측 위치129개를 관측한다. 단순히 뒤129토큰만 잘라 넣는 방식이 아니라 전체2495토큰 causal context를 계산한다. 저장 ID를 그대로 읽으며 tokenizer를 다시 실행하지 않는다.

입력 ID 해시:

- BF16 경로: `8fbe5610380766127187d520e5f4ad331a681a511bd488e80a77604f395e440b`
- AWQ 경로: `d96783b1331fbcbf5c5f20f49aeaa524584d3d4d7740c20f19877f9241824410`

기존 응답 전체 행·근거 묶음·앞선 run.json·CPU 감사 파일도 고정 해시로 대조한다. 실제 첨부로 입력/위치 대조는 이미 끝났으므로 사용자가 계획 출력을 다시 제출할 필요는 없다.

## 무엇을 판단할 것인가

1. **수집 계약:** 입력·설정·파라미터·배열 해시,6회·4비교, 유한성, BF16 반복 정확 일치를 확인한다. 실패하면 기존 파일을 지우지 않고 중단 보고를 검토한다.
2. **BF16 종료 anchor:** BF16 경로의 마지막 예측에서 B의 EOS가 수학적 top-p 후보에 남는지 먼저 확인한다. 남지 않으면 과거 실제 생성과 이번 full-sequence/no-cache 진단의 차이를 조사하며 “AWQ의 종료 억제”로 해석하지 않는다.
3. **같은 prefix의 B/Q:** B 경로와 Q 경로 각각에서 EOS log-probability·후보 포함·필터 후 확률, 전체 분포 TV/JS·후보 차이를 비교한다. 각 경로의 원래 다음 토큰이 같다는 조건은 요구하지 않는다.
4. **경로 간 차이:** 같은 모델에 서로 다른 두 경로를 넣었을 때의 변화는 경로 의존성에 관한 기술 관측이다. prefix 내용이 통제된 인과 개입 또는 길이 효과의 분해라고 부르지 않는다.

T=1·top-p 전 전체 어휘 지표와 T=0.6·top-p=.95 float64 수학적 필터를 함께 저장한다. 기존 감사와 같은 token ID 오름차순 동점 정렬을 쓰고 경계 동점·KL=∞를 따로 기록한다. 실제 GPU FP32 샘플링·RNG 또는 cache 경로 재현이 아니다.

| 관측 | 허용되는 해석 |
|---|---|
| B 경로에서 B는 EOS 후보, Q는 제외/감소 | 이 고정 prefix에서의 종료 후보/확률 차이. 자연 길이 지연 원인 확증 아님 |
| B 경로에서는 양쪽 EOS 후보, Q 경로에서는 양쪽 제외 | 경로에 따라 종료 가능성이 달라지는 탐색 관측. “경로 이탈이 원인” 확증 아님 |
| 방향이 반대이거나 일관되지 않음 | 그대로 보고. EOS 억제 가설에 맞도록 입력/시점 재선택하지 않음 |
| B 자체가 원본 종료 anchor를 재현하지 못함 | 실행 경로·cache/dtype 차이를 먼저 검토. 자동 예산 확대 없음 |

위 규칙은 관측 분류이며 기능적 동등성의 수치 허용치 또는 H1 판정 기준이 아니다. 한 문제·한 시드의 사후 선택 탐색이며 독립 확인 데이터로 다시 사용하지 않는다. 두 경로의 후반부에서도 종료 지연의 전체 원인은 남을 수 있다. 결과가 불명확해도 자동 반복·위치 추가·생성 예산 확대는 하지 않는다.
