## 1. 기존 선행연구 검토의 통합

검토 범위 안에서 제안의 구성 요소 여러 개가 이미 존재한다. **차별점 후보는 새 대조군 이름이 아니라, 보류 자료에서도 확인한 참조-prefix KL 매칭이 생성 경로 전체의 길이·종료·정답 포기를 얼마나 설명하는지의 공동 평가다.** 이 질문의 완전한 선행 부재나 논문 채택 가능성을 확인한 것은 아니다.

## 2. 수락한 기여 범위

수락한 기여 범위 문장:

> 동일 BF16 모델의 공통 추론 prefix에서 출력 분포 KL을 맞춘 고정 Gaussian 가중치 교란이, AWQ-W3의 추론 길이·종료·검증된 정답 포기 변화를 함께 재현하는지 평가한다.

이 범위는 기존 H1의 비교 질문을 유지한다. 원래 ±20% 효과 재현 경계, ±5% KL 매칭 허용치, H2의 엔트로피 방향, 본검증 표본 수·검정력은 계속 미동결이다. R0에서 이를 판정하거나 바꾸지 않는다.

| 향후 관측 | 허용되는 해석 |
|---|---|
| 독립 매칭 검증을 통과한 대조군이 사전 기준 안에서 결과를 재현 | 검토한 모델·데이터·매칭·시드 범위에서 해당 대조군의 재현 근거 |
| 유효한 매칭 후 사전 기준을 넘는 차이 | 그 비교에서 잔여 차이가 있음. 특정 양자화 기전의 인과 증거는 별도 필요 |
| 매칭 실패·전제 미재현·넓은 불확실성 | 실패한 매칭, 전제 미재현 또는 판정 불가로 보고 |

어느 결과든 자동으로 논문 가치가 생기지는 않는다. R0는 위 과학적 비교에 들어가기 위한 실행·기록 점검이다. 실제 기여 판단은 후속 전제 재현, 평가·라벨 타당도, 보류 매칭과 결과의 정보량에 달려 있다.

## 5. 사전에 구분하는 완료·실패 판정

1. 승인 조건, 깨끗한 Git 작업 트리, 런타임 버전, 준비 자료의 자체 해시 및 고정 검토 참조를 먼저 확인한다. 불일치는 모델 로딩 전에 중단한다.
2. 두 BF16 시도가 모두 기록돼야 AWQ로 진행한다. BF16 실행 오류 또는 예상하지 않은 종료는 AWQ 탐색을 시작하지 않는 사유다.
3. AWQ 전체 계층 처리와 두 AWQ 시도를 기록한다. 변환 중 실패하면 부분 모델을 다시 사용하지 않고 기록을 보존한다.
4. EOS 종료와 128토큰 예산 도달을 구분한다. 예산 도달 자체를 정확도 성공이나 무제한 추론 길이로 해석하지 않는다. 128토큰 안에 최종 답이 없는 경우에도 실제 출력·종료 사유를 남긴다.
5. 실행 완료 상태는 `R0_EXECUTED_DIAGNOSTICS_PENDING_REVIEW`, model_ready는 false다. 이 상태는 실모델 함수 동등성·정확도·AWQ 재현의 인증이 아니다.

계층 출력 차이는 실제 진단값을 검토한다. 작은 무작위 모델에 적용했던 상대 RMS 5% 한도를 실제 모델의 인증 기준으로 옮기지 않는다. 실행 결과를 본 뒤 임의의 수치 기준을 만들어 이번 점검을 인증하지도 않는다. 전체 모델 logit·함수 동등성과 긴 문맥 검증은 다음 프로토콜에서 별도로 정의한다.

## 6. 완료 보고된 R0의 실행 명령 기록

**아래 명령의 실행 결과는 사용자 보고로 제출됐다. 현재는 기존 결과 검토 단계다.** 실행 절차를 보존한 기록이며 자동 재실행을 요청하지 않는다. 실행기는 로컬 자료·런타임·Git 상태를 실행 전에 대조한다.

~~~bash
conda activate quantthink
cd ~/quantthink
git switch setup/session-01-research-gates
git pull --ff-only

python scripts/run_r0.py --execute \
  --assets-dir results/local/runtime_assets_v03 \
  --upstream-dir results/local/awq_reference_v03 \
  --device cuda:0 \
  --output-dir results/local/r0_v03
~~~

기존 데이터 준비·토크나이저·합성 AWQ 검사를 반복하는 명령은 필요하지 않다. R0 이후에는 run.json과 계층 진단을 검토해 다음 실행 범위를 결정한다. R1 100문제 평가, MATH-500 확증, KL 매칭, 장문맥·H1/H2 검정은 이번 R0 수락 범위에 포함하지 않는다.
