네 응답 모두 승인된 128토큰 상한에서 중단됐다. 코드상 허용한 예산 종료이므로 실행 완료 상태와 모순되지 않는다. EOS로 자연 종료한 사례는 0개다. 모두 같은 상한에 도달했으므로 두 조건의 자연 종료 길이가 같다는 결론이나 AWQ 길이 증가 재현 결론을 낼 수 없다.

제출 텍스트에는 두 조건 모두 중간 계산의 정답 42·12와 닫는 think 태그가 나타나지만 최종 답변 작성 도중 잘렸다. 중간 정답 숫자만으로 최종 정답률을 집계하거나 검증된 정답 포기로 분류하지 않는다. 본검증의 과잉 추론·정답 포기 라벨 검증을 대신하지 않는다.

제출된 생성 시간은 약 3.68~4.37초이고 최대 할당 메모리는 약 3.58GB다. 짧은 입력 네 건의 관측이며 모델 로딩·AWQ 탐색 총비용이나 비교 처리량 결론으로 확장하지 않는다. 이번 AWQ는 양자화된 값을 BF16으로 실행하므로 native 저비트 속도 측정도 아니다.

## 3. 계층 진단의 의미

| 진단 | 최대 상대 RMS | 해당 계층 | 전체 계층 중 최대 절대 차이 |
|---|---:|---:|---:|
| scale_only_output_difference | 약 0.5686% | 0 | 16.0 |
| canonicalized_output_difference | 약 0.6008% | 1 | 32.0, 계층 2 |

계층 번호는 0부터 시작한다. 스케일 진단은 양자화 전 계층의 스케일 적용 전후 비교다. 좌표 복원 진단은 변환한 AWQ 계층과 원래 좌표로 역변환한 AWQ 계층 사이의 비교다. 두 지표를 원래 BF16 대비 AWQ의 양자화 손실·정확도 저하로 해석하지 않는다.

작은 상대 RMS만으로 함수 동등성을 인증하지 않는다. 일부 큰 최대 절대 차이는 위치·활성값 규모·가중치 및 norm/bias 잔차와 함께 검토할 항목이다. 출력 차이의 집계만으로 원인을 BF16 반올림이라고 확정하거나 구현 오류라고 단정할 수 없다. 작은 무작위 모델의 상대 RMS 5% 한도를 실제 모델의 사후 인증 기준으로 옮기지 않는다.

현재 요약에는 전체 모델 logit 비교, canonical_weight_error와 canonical_auxiliary_error의 상세 요약이 없다. 해당 값이 필요하면 기존 계층 파일에서 읽고, 제출되지 않은 값을 이미 검증한 것으로 기록하지 않는다.
