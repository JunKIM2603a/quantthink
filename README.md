# QuantThink

양자화된 추론 모델의 추론 길이 증가와 정답 포기 현상을, 교란 크기를 맞춘 대조군으로 연구하는 프로젝트다.

**현재 상태: 사용자 데이터 준비 완료 보고를 검토했다. 원본 3개를 독립적으로 해시 대조하고 개발 산출물 3개를 다시 만들어 일치를 확인했다. 2026-09-29 사용자 승인으로 세션 01을 완료했고 현재는 세션 02의 R0 실행 단계다. 사전학습 BF16/AWQ와 H1/H2는 미실행이다.**

핵심 질문은 참조 모델의 공통 prefix에서 토큰 분포 KL을 맞춘 가우시안 가중치 교란이, 강한 양자화에서 관찰되는 길이 증가와 확인된 정답 포기를 재현하는지다. H2는 국소 엔트로피와 분기 행동에 관한 초안이다. 초기 모델은 DeepSeek-R1-Distill-Qwen-1.5B이며, 7B 재현과 MATH-500 확증 평가를 계획하고 있다.

새로 전달하거나 갱신하는 안내 문서는 한국어로 작성한다. 과거 영문 문서는 검토 이력을 보존하기 위해 남겨 둔다.

가우시안 잡음 대조군이라는 발상 자체는 이미 활성 양자화 연구에 등장한다. 관련 논문 2609.23125v1과 2609.06473v1의 본문 후속 검토를 기존 문헌표와 통합해 제한된 기여 범위를 제안했다. 이 제한된 범위를 사용자 승인으로 채택했다. 평균 KL을 맞춘 대조군을 추가했다는 사실만으로 신규성을 주장하지 않는다.

## 완료된 데이터 준비와 다음 작업

사용자 보고 상태는 PREPARED_CANDIDATE_NOT_RUN_APPROVAL이다. 준비 코드 4개와 설정 해시 3개가 저장소와 일치한다. 고정 원본 3개의 바이트를 독립 대조했고, GSM8K 개발 100문제의 목록·입력·정답 파일 3개를 같은 코드와 PyArrow 20.0.0으로 재구성해 파일 해시 일치를 확인했다.

Calibration은 사용자 보고 기준 261문서에서 128 × 512 = 65,536토큰을 구성했다. 원본 179,996행의 제외·적격 집계가 맞으며, 128은 문서 수가 아닌 블록 수다. Calibration 산출물 2개의 실제 바이트와 토큰 배열은 이 환경에서 직접 검증하지 않았다. 제출 해시를 [검토 참조](configs/prepared_assets_review_v03.json)에 고정하고 R0가 로컬 자료를 이 참조와 대조하도록 연결했다.

데이터 준비·토크나이저·합성 AWQ 점검을 다시 실행할 필요는 없다. [R0 검토안](docs/R0_REVIEW_PACKET_20260929_KO.md)에 기존 문헌의 중복 범위, 제한된 연구 질문, 고정 자료, 실행·실패 기준과 승인 후 명령을 정리했다. 다음 실모델 점검은 합성 문제 2개 × BF16/AWQ, 응답당 최대 128토큰이다. AWQ calibration 비용은 별도다.

저장소 AGENTS.md 8번에 따른 제한된 기여 범위·R0 프로토콜 수락·연구 실행 승인을 기록했다. 세션 01의 종료 조건을 충족해 **QuantThink 02 — 환경 구축·BF16/AWQ 재현**으로 전환했다. [인계문의 명령](docs/HANDOFF_01_TO_02_KO.md)으로 승인된 R0를 실행한다. 실행기는 로컬 자료·런타임·Git 상태를 모델 로딩 전에 대조한다.

이번 새 자료 대조 검사 7개 통과, 기존 v0.3 연계 검사 29개 통과·3개 건너뜀이다. 건너뛴 Qwen2 검사 3개는 작성 환경의 PyTorch·Transformers 부재 때문이다. 이전 사용자 합성 GPU PASS와 이번 CPU 검사는 별개의 근거이며 실모델 실행 성공을 뜻하지 않는다.

## 결과 해석 원칙

긴 응답, 반복, 상한 도달, 올바른 중간 풀이를 버린 현상은 서로 구분한다. 평균 KL이 같아도 교란의 구조나 EOS 확률이 같다는 보장은 없다. 동등성을 입증하지 못한 결과를 곧바로 양자화 고유 메커니즘의 증거로 해석하지 않는다.

가짜 양자화 후 BF16 실행은 native 저비트 처리량 측정이 아니다. R0의 설정과 범위는 수락했으며 H1/H2·동등성 경계·후속 실험 계획은 초안이다. R1·확증·KL 매칭·장문맥·7B는 이번 R0 승인 범위에 포함하지 않는다.
