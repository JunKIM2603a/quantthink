# 단계별 세션 운영

현재 세션명: **QuantThink 01 — 저장소 점검·연구 설계 검증**

세션은 대화 길이가 아니라 산출물과 종료 조건으로 나눈다. 준비 문서 작성이나 CPU 단위 테스트 통과만으로 다음 연구 단계가 완료된 것은 아니다. 세션 전환은 대화에서 결과를 검토할 때 알리며, 외부 실행을 자동 감시하는 기능을 뜻하지 않는다.

| 세션 | 목표와 필수 산출물 | 종료 조건 |
|---|---|---|
| 01 — 저장소 점검·연구 설계 검증 | 원문 주장 검증, 신규 선행연구 충돌표, 기여 문장, 재현용 프로토콜 초안 | 중요한 출처/중복 쟁점 판정, 과장된 인과 해석 수정, 재현 프로토콜 수락 및 연구 실행 승인 기록 |
| 02 — 환경 구축·BF16/AWQ 재현 | 사용자 환경 보고서, 버전/체크포인트 고정, 평가기 검증, BF16/AWQ 산출물 | 기능적 양자화 검증, 사전에 정한 재현 기준 판정, 길이·정확도·종료 사유 및 처리량 실측 |
| 03 — 교란 매칭·대조군 검증 | 분리된 calibration/validation, weight/KL-matched noise, 온도 대조군 | 보류 데이터에서 매칭 오차 확인, 시드/분할/노이즈 범위 고정, 측정 오류 점검, H1 검정력·동등성 경계 결정 |
| 04 — H1 본검증·Main Finding | 동결된 계획에 따른 독립 평가, 문제/시드별 결과, 신뢰구간 | 동등성 지지·의미 있는 차이·판정 불가 중 근거 있는 결론; 혼합 결과도 그대로 보고 |
| 05 — 메커니즘·7B 재현 | 사전에 구분한 H2 분석, 대안 설명 통제, 규모/방법 재현 | 확인된 패턴과 일반화 한계 정리; 단순 상관을 메커니즘으로 단정하지 않음 |
| 06 — 논문·발표 구성 | main figure, contribution, limitation, 재현 가이드 | 논문 주장과 실제 근거 일치, 누락 실험 및 자료 점검 |

## 현재 01단계에서 남은 일

2609.23125v1과 2609.06473v1의 관련 본문 대조를 [후속 기록](NOVELTY_FOLLOWUP_20260929.md)에 남겼다. 원문 접근 문제는 해소했으며, 기존 문헌표와 통합한 최종 기여 판정, 토크나이저 실제 결과 확인, 실행 가능한 재현 프로토콜 수락 및 연구 실행 승인 기록이 남아 있다. 기존 보고서의 '노이즈 비교가 최초' 또는 '어느 결과든 논문이 된다'는 문구를 사용하지 않는다. 프로토콜은 아직 동결되지 않았으며, 현재 허용 작업은 문헌 검토·설계·CPU 테스트·로컬 환경 확인·CPU 토크나이저 자산 점검이다.
