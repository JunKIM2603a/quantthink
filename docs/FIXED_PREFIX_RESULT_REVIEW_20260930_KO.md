## 같은 prefix에서 관측한 차이

각 비교는 두 입력×129위치=258위치다. 아래 KL·TV는 **T=1, top-p 전 전체 vocabulary, float64 집계**다. RMS는 모든 위치/어휘 원소에 대한 제곱 평균으로 합쳤다. 같은 생성 경로에서 뽑은 위치들이므로 독립 표본258개로 취급하지 않는다.

| 비교 | D2-03 top-1 변경 | D3-01 top-1 변경 | 전체 변경 | logit RMS | 평균 KL | 최대 TV |
|---|---:|---:|---:|---:|---:|---:|
| B→B_repeat, BF16 반복 |0/129|0/129|0/258|0|0|0|
| B→S, 저장 scale만 적용 |0/129|1/129|1/258|0.037954|0.00038052|0.054287|
| B→Q, AWQ 재구성 |7/129|15/129|22/258|0.832596|0.08171374|0.632749|
| Q→C, 원래 좌표 복원 |0/129|3/129|3/258|0.039301|0.00038833|0.049160|
| C→Cw, B의 norm/bias 복사 |0/129|1/129|1/258|0.038966|0.00038238|0.034700|

B 반복은 모든 선택 logit 값이 동일하다고 기록됐고 두 입력의 `.npy` 해시도 각각 같다. 해당 조건에서의 반복 확인이다. 모든 하드웨어·cache 경로의 결정성을 인증하지 않는다.

B→Q의 변경은22/258(약8.53%)이고 이 중21곳은 기준 top-1/2 margin이 양수다. 기존 두 산수의 검열 길이만 보고 판단하던 단계에서, 같은 입력의 분포 차이를 직접 기록하는 단계로 진전했다. 다만 B→Q에는 저장 scale/clip/W3 재구성 경로가 포함된다. 양자화만의 순수 인과 효과, 자연 종료 길이 또는 정확도 차이를 이 값으로 분리하지 않는다. KL은 가산적 원인 분해량이 아니며 KL 매칭 실험을 수행한 것도 아니다.

| 비교 | 입력·위치 | 기준 margin | 읽는 방법 |
|---|---|---:|---|

기준 동점이라는 사실만으로 새 argmax가 원래 공동1위 집합 안에 있는지까지 알 수는 없다. 원시 배열 감사에서 그 집합 관계와 변경 후 margin을 확인한다. 동점을 구분하더라도 분포 차이는 남는다. 현재 결과에 맞춰 허용치를 정해 스케일/좌표 동등성을 PASS로 바꾸지 않는다.

모든 norm56개에 비영 잔차가 있다. 두 float64 RMS는 기존 R0 상세 요약과 일치하며, 이번에는 실제 BF16 재적용 기준과 분리됐다. 위 상대 RMS는 전체 원소의 RMS 오차를 전체 참조 RMS로 나눈 값이다. bias의 **오차가0**이라는 뜻이며 bias 자체가 모두0이라는 뜻은 아니다.

Cw는 선형 weight를 유지하고 원래 norm/bias를 복사한 상태다. C→Cw logit 변화가 관측됐으므로 이 잔차의 영향은0이 아니다. Cw를 주 AWQ 생성 조건으로 자동 교체하거나 복구의 정답으로 확정하지 않는다.

## EOS와 종료 해석

B→Q에서 EOS log-probability 변화의 평균은 +1.55035이며234/258곳에서 EOS 확률이 증가했다. B의 EOS 확률 범위는 약7.10×10⁻¹⁵~8.22×10⁻⁹, Q는 약2.33×10⁻¹³~3.46×10⁻⁸이다. **이 선택 구간에서는 단순한 “AWQ가 EOS 확률을 낮춰서 길어진다” 설명을 뒷받침하지 않는다.**

절대 확률이 작고 실제 생성은 T=0.6·top-p=0.95를 사용했다. EOS가 필터에서 제외될 수 있으며 이번 입력은 BF16의 앞2048토큰이다. AWQ가 실제로 방문한 경로나 종료 직전 경로를 대표하지 않는다. 자유 생성·EOS 종료는 이번 진단에서 전혀 실행하지 않았다. 기존43개 검열의 미관측 최종 답, 전체 자연 길이 또는 H1/H2를 이 값으로 판정하지 않는다.

진단은 window=None·use_cache=false·최대2127문맥으로 실행됐다. 기존4096 경계의 실제 생성 cache/마스크 영향을 해소한 실험도 아니다.

## 작성 당시 후속: 기존 배열만 읽는 CPU 감사 — 이후 완료

[audit_fixed_prefix_logits.py](../scripts/audit_fixed_prefix_logits.py)는 다음을 수행한다.

1. 검토한 run.json 바이트·실행 당시 설정/상태·기존 코드 해시를 고정 대조한다. 현재 갱신된 research_status.json을 과거 실행 해시와 잘못 비교하지 않는다.
2. 12개 `.npy`의 SHA-256·shape·dtype·유한성을 확인하고 원본 비교10개의 모든 위치별 수치를 재계산한다. 범주/인덱스는 정확히, 부동소수점은 rtol=1e-10·atol=1e-12로 대조한다. 이는 동일 자료의 집계 재계산 오차이며 **모델 동등성 허용치가 아니다**.
3. 같은 배열에 T=0.6·top-p=0.95를 수학적으로 적용해 EOS 후보 포함·확률·순위, 분포 TV/JS, 서로 다른 후보 집합을 기록한다. 후보가 사라져 KL이 무한대면 JSON의 null과 명시적 flag를 함께 기록한다.
4. top-1 공동최댓값 집합과 top-p 경계 동점을 기록한다. 해시를 끝에서 다시 확인하고 새 `logits_audit_v01.json`만 저장한다. 기존 출력이 있으면 덮어쓰지 않는다.

분포 진단은 NumPy float64와 token ID 오름차순 동점 정렬을 명시한다. [고정 Transformers4.51.3의 TopPLogitsWarper](https://github.com/huggingface/transformers/blob/v4.51.3/src/transformers/generation/logits_process.py)에서 확인한 오름차순 누적확률 ≤1−top-p 제거·최소1개 유지 규칙을 따른다. 실제 GPU의 FP32 연산·동점 정렬 순서·RNG·생성 cache를 재현하지 않는다. 경계에서 동점 일부만 선택됐으면 이를 숨기지 않으며, 이론적 EOS 제외를 모든 GPU 생성 경로의 제외로 확대하지 않는다. 새 forward·토크나이저·모델/자료 다운로드는 없다.

```bash
conda activate quantthink
cd ~/quantthink
git switch setup/session-01-research-gates &&
git pull --ff-only &&
python scripts/audit_fixed_prefix_logits.py
```

위 명령은 당시 안내 이력이며 재실행할 필요 없다. **`results/local/fixed_prefix_v01/logits_audit_v01.json`**은 이미 받아 검토했다. 약0.94GB 원시 `.npy`는 로컬에 보존하고 공개 Git에 올리지 않는다. 파일 누락·해시 불일치가 나면 해당 오류를 검토하며 추론을 자동 재실행하지 않는다. 저장 자료의 읽기 전용 감사이므로 새 모델 실행 승인이나 기존 승인 재확인이 필요하지 않다.
