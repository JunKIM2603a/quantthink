## 4. R0가 검토한 자료를 사용하도록 연결

기존 R0는 준비 보고서 안의 해시와 로컬 파일이 일치하는지 확인했다. 이번에는 **저장소에 고정한 검토 참조와도 대조**하도록 보완했다. 따라서 다른 토큰·목록으로 파일과 자체 보고서를 함께 바꿔도 이번 검토 자료와 다르면 모델 로딩 전에 중단한다.

출처·패키지·준비 코드·산출물 해시, 개발·calibration 집계와 선택 해시를 대조하고 블록 크기·토큰 형식도 확인한다. 실행 보고서에는 검토 참조 자체의 정규화 해시를 남긴다. 연구 승인 조건 검사는 계속 이 모든 과정과 네트워크·모델 로딩보다 먼저 수행한다.

새 관련 검사 **7개 통과**, 기존 v0.3 연계 검사 **29개 통과·3개 건너뜀**이다. 건너뛴 3개는 작성 환경에 PyTorch·Transformers가 없어 실행하지 못한 Qwen2 검사다. 추가 검사는 합성 파일을 사용했으며, 실제 사용자 calibration 파일을 검증하거나 모델을 실행한 결과로 합산하지 않는다. 구문과 문서·상태 일관성도 확인했다.
